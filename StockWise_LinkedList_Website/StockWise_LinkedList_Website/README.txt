StockWise Linked List Website
=============================

Run:
1. Extract this folder.
2. Open index.html in your browser.
3. No Node.js, API, server, C++ executable, or package installation is needed.

Features:
- Add product (inserted at HEAD, matching the C++ linked-list example)
- Display products, search by ID/name, edit, delete
- Low-stock status (5 or fewer), inventory totals and value
- Visual linked-list nodes with arrows ending in NULL
- Saves website data in this browser using localStorage

Important:
This is a separate website demonstration. It does not connect to or update the C++ console program. The linked-list concept is implemented in JavaScript for the visual dashboard.
